    Automatización · SysReptor (Vagrant + Docker)

    ➡️ Práctica correspondente: Informes con SysReptor

    SysReptor é unha aplicación web de redacción de informes de pentest. Este documento monta o escenario completo de principio a fin: unha VM Kali creada con Vagrant e, dentro dela, Docker co instalador oficial de SysReptor. Seguindo só estes pasos tes o escenario funcionando.

    Oficial: sysreptor.com · Docs: docs.sysreptor.com · Guía base Kali: emvee-nl

    Requisitos

    • VirtualBox 7.1+ e Vagrant 2.4+ no host.
    • RAM: SysReptor recomenda 8 GB. A VM crea a Kali con 2 GB (dabondo para probar); se o vas usar intensivamente, sobe vb.memory no Vagrantfile.

    Recursos da VM: por defecto vs. recomendado

    O laboratorio arrinca cunha configuración mínima para probar:

    • Por defecto (Vagrantfile): vb.cpus = 2 (2 núcleos) e vb.memory = "2048" (2 GB de RAM).
    • Recomendación oficial de SysReptor: arredor de 8 GB de RAM (e 2 CPU / ~8 GB de disco libre) para un uso real.

    Se notas a máquina virtual lenta ou pouco fluída (sobre todo ao arrincar os contedores Docker ou ao renderizar informes), aumenta os recursos editando estas liñas no Vagrantfile antes de vagrant up (ou con vagrant reload despois de cambialas):

    vb.memory = "4096"   # ou "8192" se o host o permite
vb.cpus   = 4

    Non asignes máis RAM/CPU da que o teu equipo poida ceder sen quedar sen recursos para o host.

    Paso 1 — Crear o Vagrantfile

    No host, nun cartafol de traballo, crea un ficheiro chamado Vagrantfile con este contido:

    Vagrant.configure("2") do |config|

  # ============================================================
  # Máquina SysReptor: KALI-SysReptor
  # ============================================================
  config.vm.define "KALI-SysReptor" do |kali_a|

    kali_a.vm.box = "kalilinux/rolling"
    kali_a.vm.hostname = "KALI-SysReptor"
    kali_a.vm.boot_timeout = 1800

    # ------------------------------------------------------------
    # VirtualBox
    # ------------------------------------------------------------
    kali_a.vm.provider "virtualbox" do |vb|
      vb.gui = true
      vb.memory = "2048"
      vb.cpus = 2
      vb.name = "KALI-SysReptor"

      vb.customize ["modifyvm", :id, "--groups", "/HE/Templates"]
      vb.customize ["modifyvm", :id, "--graphicscontroller", "vboxsvga"]
    end

    # ------------------------------------------------------------
    # Rede interna "template"
    #
    # Rede illada do laboratorio (mesma base para toda a clase).
    # SysReptor accédese DENTRO da VM (http://127.0.0.1:8000), así
    # que non precisa rede host-only; mantense a rede interna.
    #
    # auto_config: false -> Vagrant non toca a rede do convidado;
    # a IP configúrase con NetworkManager na PROVISION 1 (en Kali
    # a configuración automática de Vagrant non se aplica ben).
    # ------------------------------------------------------------
    kali_a.vm.network "private_network",
      ip: "192.168.120.100",
      virtualbox__intnet: "template",
      adapter: 2,
      auto_config: false


    # ============================================================
    # PROVISION 1
    # Rede interna + APT + keyring + certificados
    # ============================================================
    kali_a.vm.provision "shell", inline: <<-'SHELL'

set -euo pipefail

export DEBIAN_FRONTEND=noninteractive

echo
echo "============================================================"
echo " KALI-SYSREPTOR - PROVISION 1"
echo " Configurando rede, APT e repositorios Kali"
echo "============================================================"
echo

# ------------------------------------------------------------
# 1. Comprobar distribución
# ------------------------------------------------------------

if [ -f /etc/os-release ]; then
    . /etc/os-release
    echo "[INFO] Sistema: ${PRETTY_NAME:-descoñecido}"
fi


# ------------------------------------------------------------
# 2. Rede interna (segunda interface)
#
# Detectamos a interface NAT (a que ten a ruta por defecto) e
# collemos a outra interface como rede interna "template".
# ------------------------------------------------------------

INTNET_IP="192.168.120.100"
INTNET_PREFIX="24"

NAT_IF="$(ip -o -4 route show default | awk '{print $5; exit}')"
HO_IF="$(ls /sys/class/net | grep -Ev "^(lo|${NAT_IF})$" | head -n1 || true)"

echo "[REDE] Interface NAT: ${NAT_IF:-descoñecida}"
echo "[REDE] Interface interna: ${HO_IF:-non atopada}"

if [ -n "${HO_IF}" ]; then

    if command -v nmcli >/dev/null 2>&1 && systemctl is-active --quiet NetworkManager; then

        echo "[REDE] Configurando ${HO_IF} con NetworkManager..."

        # Eliminar conexións previas sobre esa interface
        nmcli -t -f NAME,DEVICE con show | awk -F: -v d="${HO_IF}" '$2==d {print $1}' \
          | while read -r C; do nmcli con delete "${C}" || true; done
        nmcli con delete template >/dev/null 2>&1 || true

        nmcli con add type ethernet ifname "${HO_IF}" con-name template \
          ipv4.method manual \
          ipv4.addresses "${INTNET_IP}/${INTNET_PREFIX}" \
          ipv4.never-default yes \
          ipv6.method disabled \
          connection.autoconnect yes

        nmcli con up template || true

    else

        echo "[REDE] NetworkManager non dispoñible; usando ifupdown..."

        mkdir -p /etc/network/interfaces.d
        cat > /etc/network/interfaces.d/template <<EOF
auto ${HO_IF}
iface ${HO_IF} inet static
    address ${INTNET_IP}/${INTNET_PREFIX}
EOF
        ip addr add "${INTNET_IP}/${INTNET_PREFIX}" dev "${HO_IF}" 2>/dev/null || true
        ip link set "${HO_IF}" up || true

    fi

else

    echo "[WARN] Non se atopou a interface interna."

fi


# ------------------------------------------------------------
# 3. Eliminar configuracións antigas/conflictivas de Kali
#
# As versións actuais poden empregar:
#   /etc/apt/sources.list.d/debian.sources
#
# Non asumimos que /etc/apt/sources.list exista.
# ------------------------------------------------------------

echo "[APT] Limpando configuracións de repositorios anteriores..."

mkdir -p /etc/apt/sources.list.d

rm -f /etc/apt/sources.list.d/debian.sources
rm -f /etc/apt/sources.list.d/kali.sources
rm -f /etc/apt/sources.list.d/kali.list


# ------------------------------------------------------------
# 4. Crear repositorio oficial de Kali en formato deb822
# ------------------------------------------------------------

echo "[APT] Creando /etc/apt/sources.list.d/kali.sources"

cat > /etc/apt/sources.list.d/kali.sources <<'EOF'
Types: deb
URIs: http://http.kali.org/kali
Suites: kali-rolling
Components: main non-free-firmware contrib non-free
EOF


# ------------------------------------------------------------
# 5. Instalar/actualizar keyring de Kali
#
# Descarga por HTTP para evitar problemas iniciais de TLS.
# ------------------------------------------------------------

echo "[APT] Descargando Kali archive keyring..."

mkdir -p /usr/share/keyrings

if command -v wget >/dev/null 2>&1; then

    wget -q \
      http://archive.kali.org/archive-keyring.gpg \
      -O /usr/share/keyrings/kali-archive-keyring.gpg

else

    echo "[ERROR] wget non está instalado."
    exit 1

fi


# ------------------------------------------------------------
# 6. Primeira actualización APT
# ------------------------------------------------------------

echo "[APT] Executando apt-get update..."

apt-get clean
rm -rf /var/lib/apt/lists/*

apt-get update -y


# ------------------------------------------------------------
# 7. Instalar ferramentas básicas
# ------------------------------------------------------------

echo "[APT] Instalando certificados e ferramentas básicas..."

apt-get install -y --no-install-recommends \
    kali-archive-keyring \
    ca-certificates \
    apt-transport-https \
    curl \
    wget \
    gnupg \
    lsb-release


# ------------------------------------------------------------
# 8. Configurar APT para usar HTTPS
# ------------------------------------------------------------

echo "[APT] Cambiando repositorio a HTTPS..."

cat > /etc/apt/sources.list.d/kali.sources <<'EOF'
Types: deb
URIs: https://kali.download/kali
Suites: kali-rolling
Components: main non-free-firmware contrib non-free
Signed-By: /usr/share/keyrings/kali-archive-keyring.gpg
EOF


# ------------------------------------------------------------
# 9. Configuración de APT
# ------------------------------------------------------------

cat > /etc/apt/apt.conf.d/99vagrant-kali <<'EOF'
Acquire::Retries "5";

Acquire::http::Timeout "40";
Acquire::https::Timeout "40";

Acquire::ForceIPv4 "true";

APT::Get::Assume-Yes "true";
EOF


# ------------------------------------------------------------
# 10. Limpar índices e actualizar outra vez
# ------------------------------------------------------------

echo "[APT] Actualizando usando HTTPS..."

apt-get clean
rm -rf /var/lib/apt/lists/*

apt-get update -y


# ------------------------------------------------------------
# 11. Sincronización horaria
# ------------------------------------------------------------

echo "[TIME] Configurando sincronización horaria..."

timedatectl set-ntp true || true

timedatectl set-timezone Europe/Madrid || true


echo
echo "============================================================"
echo " PROVISION 1 COMPLETADA"
echo "============================================================"
echo

SHELL


    # ============================================================
    # PROVISION 2
    # Sistema + GRUB + XFCE + SSH + usuario Kali + teclado
    # ============================================================

    kali_a.vm.provision "shell", inline: <<-'SHELL'

set -euo pipefail

export DEBIAN_FRONTEND=noninteractive

echo
echo "============================================================"
echo " KALI-SYSREPTOR - PROVISION 2"
echo " Sistema, XFCE, SSH e configuración"
echo "============================================================"
echo


# ------------------------------------------------------------
# 1. Comprobar repositorio
# ------------------------------------------------------------

echo "[APT] Repositorios configurados:"

if [ -f /etc/apt/sources.list.d/kali.sources ]; then
    cat /etc/apt/sources.list.d/kali.sources
fi

echo


# ------------------------------------------------------------
# 2. Actualizar índices
# ------------------------------------------------------------

echo "[APT] Actualizando índices..."

apt-get update -y


# ------------------------------------------------------------
# 3. Resolver posibles paquetes pendentes
# ------------------------------------------------------------

echo "[APT] Comprobando paquetes pendentes..."

dpkg --configure -a || true

apt-get -f install -y || true


# ------------------------------------------------------------
# 4. Actualizar sistema
#
# --force-confdef + --force-confold: consérvanse os ficheiros de
# configuración existentes (p.ex. sshd_config do box de Vagrant).
# ------------------------------------------------------------

echo "[APT] Executando dist-upgrade..."

apt-get -y \
  -o Dpkg::Options::="--force-confdef" \
  -o Dpkg::Options::="--force-confold" \
  dist-upgrade || {

    echo "[WARN] dist-upgrade tivo problemas."
    echo "[APT] Intentando recuperar paquetes..."

    dpkg --configure -a || true

    apt-get -f install -y || true

    apt-get update -y || true
}


# ------------------------------------------------------------
# 5. GRUB
#
# Non asumimos que o dispositivo raíz sexa /dev/sda.
# ------------------------------------------------------------

echo
echo "[GRUB] Configurando GRUB..."

apt-get install -y --no-install-recommends \
    debconf-utils \
    grub-pc \
    grub2-common || true


ROOTDEV="$(findmnt -n -o SOURCE / || true)"

echo "[GRUB] ROOTDEV=${ROOTDEV}"


# Intentar determinar disco pai
PARENT=""

if [ -n "${ROOTDEV}" ]; then

    PARENT="$(lsblk -no pkname "${ROOTDEV}" 2>/dev/null | head -n1 || true)"

fi


# Só aceptamos discos reais (sdX, vdX, nvmeX); senón, /dev/sda
case "${PARENT}" in
    sd*|vd*|nvme*) DISK="/dev/${PARENT}" ;;
    *)             DISK="/dev/sda" ;;
esac


echo "[GRUB] Disco seleccionado: ${DISK}"


printf 'grub-pc grub-pc/install_devices multiselect %s\n' \
    "${DISK}" | debconf-set-selections || true

printf 'grub-pc grub-pc/install_devices_empty boolean false\n' \
    | debconf-set-selections || true

printf 'grub-pc grub2/linux_cmdline string\n' \
    | debconf-set-selections || true

printf 'grub-pc grub-pc/kickseed boolean false\n' \
    | debconf-set-selections || true


dpkg-reconfigure -f noninteractive grub-pc || true


# ------------------------------------------------------------
# 6. Instalar escritorio XFCE + LightDM + ferramentas
# ------------------------------------------------------------

echo
echo "[DESKTOP] Instalando XFCE, LightDM e ferramentas..."

PKGS="
xfce4
xfce4-goodies
lightdm
keyboard-configuration
console-setup
zsh
whois
openssh-server
ca-certificates
curl
wget
git
sudo
vim
nano
net-tools
iproute2
htop
unzip
"

INSTALL_OK=false

for i in 1 2 3 4 5; do

    echo
    echo "[APT] Intento de instalación ${i}/5..."

    if apt-get install -y --no-install-recommends ${PKGS}; then

        INSTALL_OK=true
        break

    fi

    echo
    echo "[WARN] O intento ${i} fallou."
    echo "[APT] Intentando reparar paquetes..."

    dpkg --configure -a || true

    apt-get -f install -y || true

    apt-get update -y || true

    sleep 5

done


if [ "${INSTALL_OK}" != "true" ]; then

    echo "[ERROR] Non se puideron instalar os paquetes principais."
    exit 1

fi


# ------------------------------------------------------------
# 7. Seleccionar LightDM como display manager
# ------------------------------------------------------------

echo
echo "[LIGHTDM] Configurando LightDM..."

if command -v debconf-set-selections >/dev/null 2>&1; then

    echo "lightdm shared/default-x-display-manager select lightdm" \
      | debconf-set-selections || true

fi

dpkg-reconfigure lightdm -f noninteractive || true


# ------------------------------------------------------------
# 8. Crear usuario kali se non existe
# ------------------------------------------------------------

echo
echo "[USER] Comprobando usuario kali..."

if ! id -u kali >/dev/null 2>&1; then

    echo "[USER] Creando usuario kali..."

    useradd \
      -m \
      -d /home/kali \
      -s /usr/bin/zsh \
      kali

fi


# ------------------------------------------------------------
# 9. Configurar contrasinal de kali
# ------------------------------------------------------------

echo "[USER] Configurando contrasinal..."

echo 'kali:kali' | chpasswd


# ------------------------------------------------------------
# 10. Engadir sudo
#
# Necesario: a instalación de SysReptor execútase con sudo.
# ------------------------------------------------------------

echo "[USER] Configurando sudo..."

usermod -aG sudo kali || true

usermod -aG kali-trusted kali || true


# ------------------------------------------------------------
# 11. Permitir sudo sen contrasinal
#
# Útil para Vagrant/contorna de laboratorio.
# ------------------------------------------------------------

cat > /etc/sudoers.d/kali <<'EOF'
kali ALL=(ALL) NOPASSWD:ALL
EOF

chmod 440 /etc/sudoers.d/kali


# ------------------------------------------------------------
# 12. SSH
# ------------------------------------------------------------

echo
echo "[SSH] Configurando SSH..."

systemctl enable ssh || true
systemctl restart ssh || true


# ------------------------------------------------------------
# 13. Teclado español (consola, Xorg, LightDM e XFCE)
#
# - debconf + /etc/default/keyboard -> consola (aplícase ao arrincar)
# - /etc/X11/xorg.conf.d            -> LightDM e sesións gráficas
# - xfconf por usuario              -> XFCE non sobrescribe o layout
# ------------------------------------------------------------

echo
echo "[KEYBOARD] Configurando teclado español..."

# 13.1 debconf + /etc/default/keyboard
cat <<'EOF' | debconf-set-selections
keyboard-configuration keyboard-configuration/layoutcode string es
keyboard-configuration keyboard-configuration/modelcode string pc105
keyboard-configuration keyboard-configuration/variantcode string
keyboard-configuration keyboard-configuration/optionscode string
EOF

cat > /etc/default/keyboard <<'EOF'
XKBMODEL="pc105"
XKBLAYOUT="es"
XKBVARIANT=""
XKBOPTIONS=""
BACKSPACE="guess"
EOF

dpkg-reconfigure -f noninteractive keyboard-configuration || true

# 13.2 Xorg
mkdir -p /etc/X11/xorg.conf.d

cat > /etc/X11/xorg.conf.d/00-keyboard.conf <<'EOF'
Section "InputClass"
    Identifier "system-keyboard"
    MatchIsKeyboard "on"
    Option "XkbLayout" "es"
    Option "XkbModel" "pc105"
EndSection
EOF

# 13.3 Aplicar a udev sen reiniciar
udevadm trigger --subsystem-match=input --action=change || true

# 13.4 XFCE: configuración por usuario (kali, vagrant e novos usuarios)
XFCE_KBD_XML='<?xml version="1.0" encoding="UTF-8"?>
<channel name="keyboard-layout" version="1.0">
  <property name="Default" type="empty">
    <property name="XkbDisable" type="bool" value="false"/>
    <property name="XkbLayout" type="string" value="es"/>
    <property name="XkbVariant" type="string" value=""/>
    <property name="XkbModel" type="string" value="pc105"/>
  </property>
</channel>'

XFCONF_REL=".config/xfce4/xfconf/xfce-perchannel-xml"

mkdir -p "/etc/skel/${XFCONF_REL}"
echo "${XFCE_KBD_XML}" > "/etc/skel/${XFCONF_REL}/keyboard-layout.xml"

for U in kali vagrant; do
    if id -u "${U}" >/dev/null 2>&1; then
        H="$(getent passwd "${U}" | cut -d: -f6)"
        mkdir -p "${H}/${XFCONF_REL}"
        echo "${XFCE_KBD_XML}" > "${H}/${XFCONF_REL}/keyboard-layout.xml"
        chown -R "${U}:${U}" "${H}/.config"
    fi
done

echo "[KEYBOARD] Teclado español configurado."


# ------------------------------------------------------------
# 14. Activar LightDM
#
# Só se habilita; arrincará co reinicio (vagrant reload).
# ------------------------------------------------------------

echo
echo "[LIGHTDM] Habilitando display manager..."

systemctl enable lightdm || true


# ------------------------------------------------------------
# 15. Información final
# ------------------------------------------------------------

echo
echo "============================================================"
echo " KALI-SYSREPTOR CONFIGURADA"
echo "============================================================"
echo

echo "[INFO] Hostname:"
hostname

echo
echo "[INFO] IP:"
ip -4 addr show || true

echo
echo "[INFO] SSH:"
systemctl is-active ssh || true

echo
echo "[INFO] LightDM:"
systemctl is-enabled lightdm || true

echo
echo "[INFO] Usuario:"
id kali || true

echo
echo "============================================================"
echo " FIN DE PROVISION"
echo " Executa agora: vagrant reload"
echo "============================================================"
echo

SHELL

  end
end

    Paso 2 — Crear o script install_sysreptor.sh

    No mesmo cartafol, crea install_sysreptor.sh (instala Docker e executa o instalador oficial de SysReptor):

    #!/bin/bash

# Exit immediately if a command exits with a non-zero status
set -e

# Set up Docker's apt repository.

# Update the package index
echo "Updating package index..."
sudo apt-get update

# Install required packages including sed, curl, openssl, uuid-runtime, and coreutils
echo "Installing required packages..."
sudo apt-get install -y sed curl openssl uuid-runtime coreutils ca-certificates

# Add Docker's official GPG key
echo "Adding Docker's official GPG key..."
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/debian/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Add the Docker repository to Apt sources
echo "Adding Docker repository to Apt sources..."
echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/debian \
  bookworm stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

# Update the package index again
echo "Updating package index again..."
sudo apt-get update

# Install Docker
echo "Installing Docker..."
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin

# Start and enable Docker service
echo "Starting and enabling Docker service..."
sudo systemctl start docker
sudo systemctl enable docker

# Verify Docker installation
echo "Verifying Docker installation..."
sudo docker run hello-world

echo "Docker installation completed successfully!"

# Download the install.sh script
echo "Downloading the install.sh script..."
wget https://docs.sysreptor.com/install.sh

# Make the script executable
echo "Making install.sh executable..."
chmod +x install.sh

# Prompt user for confirmation to run the install script
read -p "Do you want to run the install.sh script? (y/n): " choice

if [[ "$choice" == "y" || "$choice" == "Y" ]]; then
    echo "Running install.sh..."
    sudo ./install.sh
else
    echo "You chose not to run the install.sh script from Sysreptor."
    echo "You can run the following commands manually if needed:"
    echo "wget https://docs.sysreptor.com/install.sh"
    echo "chmod +x install.sh"
    echo "sudo ./install.sh"
fi

    Paso 3 — Levantar a VM

    No host, dentro do cartafol co Vagrantfile:

    vagrant up        # crea e provisiona a VM Kali (actualiza o sistema: tarda)
vagrant reload    # reinicia aplicando a configuración

    Paso 4 — Instalar SysReptor dentro da VM

    Fai login gráfico en Kali (usuario kali, contrasinal kali) e, nunha consola:

    cd /vagrant                       # cartafol compartido co host (onde están os ficheiros)
sudo bash install_sysreptor.sh    # instala Docker + SysReptor (install.sh oficial)

    Respostas ás preguntas do script

    O script install_sysreptor.sh e, dentro, o instalador oficial de SysReptor son interactivos. Responde así:

    • Do you want to run the install.sh script? (y/n): → y
      • Lanza o instalador oficial de SysReptor.
    • License key (leave blank for Community Edition; you can upgrade anytime later): → (en branco, Intro)
      • Usamos a Community Edition.
    • Encrypt files and database? [y/n]: → n
      • Laboratorio; sen cifrado é máis simple de operar.
    • Should we setup a webserver (Caddy in Docker) ... [y/n]: → n
      • Accédese dentro da VM por 127.0.0.1:8000; non se expón á rede.
    • Copy your password now. Copied? [y/n]: → y
      • Copia antes o contrasinal de reptor: só se amosa aquí.
    • Enable automatic updates? [y/n]: → y
      • Actualiza SysReptor automaticamente cada día á medianoite; recomendable para manter o contedor ao día.

    Copia o contrasinal nese momento

    O contrasinal de reptor só se amosa unha vez (na liña Password:). Cópiao antes de responder y a «Copy your password now. Copied?». O usuario é sempre reptor.

    Paso 5 — Acceder ao login

    Dentro da VM, abre SysReptor no navegador:
