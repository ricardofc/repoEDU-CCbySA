    Práctica Taller: pwn.college — primeiros retos e funcionamento do Dojo

    Obxectivo

    Coñecer o funcionamento de pwn.college e resolver os primeiros retos do dojo Start Here, empregando os contornos de terminal, Visual Studio Code e escritorio Linux que ofrece a plataforma.

    Ao rematar a práctica, o alumnado deberá ser capaz de:

    • Acceder a un dojo e identificar a súa organización en módulos e retos (challenges).
    • Iniciar, executar e reiniciar un reto nun laboratorio remoto.
    • Utilizar os tres contornos de traballo accesibles desde o navegador: Terminal, Code (VS Code) e Desktop.
    • Obter unha flag, enviala e comprobar que o reto aparece como completado.
    • Diferenciar o contorno dun reto, o ficheiro /flag e o proceso de validación.

    Antes de comezar

    Esta práctica complementa a Introdución a pwn.college. A súa finalidade é aprender a manexar a plataforma, non realizar un pentest completo nin atacar sistemas externos.

    Escenario

    Elemento Descrición
    Plataforma pwn.college
    Dojo Start Here
    Módulo Using the Dojo
    Máquina atacante Contorno remoto proporcionado por pwn.college
    Acceso Navegador web e conta gratuíta
    Kali Linux / VirtualBox / VPN Non son necesarios para esta práctica
    Duración orientativa 60–90 minutos

    Normas da plataforma

    pwn.college solicita expresamente que non se publiquen na Internet solucións completas (write-ups), vídeos ou retransmisións de resolución de retos. Non inclúas flags nas capturas nin publiques o informe nun repositorio aberto.

    Pasos básicos

    Paso 1. Crear unha conta e acceder ao dojo

    1. Acceder a https://pwn.college/register.
    2. Ler as Ground Rules e completar o rexistro gratuíto. Se xa se dispón dunha conta, iniciar sesión.
    3. Acceder a Start Here.
    4. Identificar o módulo Using the Dojo e acceder ao seu listado de retos.
    5. Localizar os recursos teóricos e os exercicios prácticos. Observar que os retos se identifican polo seu nome e permiten iniciar un contorno.

    Rexistro

    No formulario hai que escribir exactamente a frase de aceptación das normas que amosa a propia plataforma. Non entregues capturas que amosen correo electrónico, contrasinais ou outros datos persoais.

    Paso 2. Primeiro reto: Using the Terminal

    1. No módulo Using the Dojo, abrir Using the Terminal.
    2. Premer Start para iniciar o reto.
    3. Agardar a que apareza o terminal no propio navegador.
    4. Ler a mensaxe e as instrucións do reto.
    5. Localizar a flag proporcionada polo exercicio.
    6. Introducila no campo Flag da páxina do reto e enviala.
    7. Comprobar a mensaxe de validación e o rexistro do reto como resolto.

    Que é unha flag?

    É un token que demostra que se completou o reto. Debe entregarse no formulario da plataforma, non copiarse no informe público nin compartirse con outros estudantes.

    Comprobación: o reto Using the Terminal figura como completado.

    Paso 3. Segundo reto: Using the VSCode Workspace

    1. Abrir Using the VSCode Workspace e iniciar o reto con Start.
    2. Localizar o selector de contorno de traballo baixo o panel interactivo.
    3. Cambiar de Terminal a Code, que abre o contorno de Visual Studio Code no navegador.
    4. Seguir as instrucións do propio reto para traballar no terminal integrado do editor.
    5. Obter a flag, enviala e comprobar a validación.

    Comprobación: identificaches a diferenza entre o terminal web e o terminal integrado en VS Code, e o segundo reto aparece como completado.

    Paso 4. Terceiro reto: Using the GUI Desktop

    1. Abrir Using the GUI Desktop e iniciar o reto.
    2. No selector de contorno, escoller Desktop.
    3. Esperar a que se abra o escritorio gráfico de Linux.
    4. Seguir as instrucións do exercicio para utilizar unha terminal dentro do escritorio.
    5. Enviar a flag e verificar a resolución.

    Comprobación: completaches tres retos utilizando tres interfaces distintas sobre o contorno remoto da plataforma.

    Paso 5. Coñecer como se executan os programas dos retos

    1. No mesmo módulo, localizar The Challenge Environment → Challenge Programs.
    2. Ler a descrición e iniciar o exercicio.
    3. Utilizar o terminal para identificar os ficheiros do reto e executar o programa indicado nas instrucións oficiais.
    4. Observar a saída do programa e comprobar como se entrega a flag.
    5. Enviar a flag para acreditar a resolución.

    Para orientarse pola terminal pódense empregar comandos básicos que non resolven por si mesmos o exercicio:

    pwd
whoami
ls
ls -l

    Aprender a interpretar os exercicios

    Nos seguintes dojos non sempre aparecerá automaticamente a flag. Será necesario comprender as instrucións, localizar ficheiros ou programas e executar as accións que corresponda. Se necesitas reforzo, continúa por Linux Luminarium.

    Paso 6. Reiniciar un reto e comprobar o progreso

    1. Localizar Restarting Challenges no módulo Using the Dojo.
    2. Ler as instrucións e realizar o reto para comprender cando cómpre reiniciar o contorno.
    3. Volver ao listado do módulo e comprobar que os retos xa superados aparecen rexistrados.
    4. Identificar onde se consulta o progreso do dojo e a clasificación (scoreboard).

    Reinicio e progreso

    Reiniciar un contorno de reto non implica necesariamente eliminar do perfil as solucións que xa foron validadas. Cómpre distinguir o estado temporal da sesión do progreso rexistrado na plataforma.
